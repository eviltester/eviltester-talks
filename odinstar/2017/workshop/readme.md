## OdinSTAR 2017 Workshop - Technical Web Testing and Automating From the Web Developer Tools

This hands-on workshop uses browser developer tools and the JavaScript console to inspect, manipulate, test, and automate browser applications.

## Overview

Through demonstrations, hands-on exercises, and challenges, the workshop shows how to interact with, test, and automate simple web applications from the browser.

The material covers browser developer tools, JavaScript console use, DOM inspection and manipulation, simple JavaScript automation, and browser-based application investigation.
