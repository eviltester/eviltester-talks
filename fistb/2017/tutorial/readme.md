## Overview

Web based applications often offer more than a GUI to interact with. Very often they have an API layer, and that layer needs testing.

This tutorial covers REST web service basics, tools for interacting with REST APIs, exploratory API testing, HTTP requests and responses, proxies, and approaches for automating REST APIs.
