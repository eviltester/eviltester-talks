## Workshop

The workshop uses Tracks to explore different testing approaches. The lightning talks cover Alan's Model, Observe, Reflect, Interrogate, Manipulate model; note taking; test ideas and intelligence; constraints and data creation; and looking at an application as an artefact and as a system. Later slides provide exploratory prompts, debrief questions and practical challenges for web, API and automated testing.
