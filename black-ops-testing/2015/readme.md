# Black Ops Testing Workshop — January 2015

James Lyndsay, Tony Bruce, Steve Green and Alan Richardson presented this practical workshop at Skills Matter, London, on 23 January 2015.

- [Workshop slides, PDF and facilitation notes](workshop/)
- [Conference page on EvilTester.com](https://www.eviltester.com/conference/blackopstesting2015_conference/)

The exercises use Tracks, an open-source Getting Things Done application with web, mobile and API interfaces. The deck combines the four presenters' lightning talks, testing and debrief prompts, and practical challenges.

All 60 slides are retained as Markdown and a PDF in `workshop/export/`. The large images on slides 23–26 are omitted from both formats; their text and original numbering remain. Only images referenced by the Markdown are included. The PowerPoint conversion source, original unedited exports and recordings are excluded from this repository.
