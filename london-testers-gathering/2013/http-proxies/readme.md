## The Evil Tester's Guide to HTTP Proxies and Browser Developer Tools

Alan Richardson's half-day workshop at the London Tester Gathering Workshops in October 2013.

More details:

https://www.eviltester.com/conference/ltgw2013_proxies_conference/

The workshop combines technical-testing models with practical work using Fiddler, BurpSuite, ZAP, and browser developer tools. It starts with login testing against Google Gruyere, followed by debriefs, proxy exercises, and browser-tool exploration.

## Conversion and Selection

All 59 slides from `TheEvilTesterGuideToHTTPProxiesAndDeveloperToolsTutorial.odp` and all 34 slides from `TheEvilTestersToolOverviewOfHTTPProxies.pptx` are retained in source order as editable Markdown text and lists. Seven slides also retain PNG renders to preserve diagram relationships, callouts, and layout. The one-slide `LTG 2013 Tutorial Links.pptx` is represented by `links.md`.

Only referenced images are included, with matching native assets shared between the two decks. Browser logos, diagrams, screenshots, and historical course/book artwork are retained from the original presentations.

The 109-slide proxy-course PowerPoint under `httpProxiesTutorial/`, its 25-slide web-testing background deck, the workshop-outline mind map, and the separate blurb are omitted. The selected event deck and linked support guide are the conference release; the background decks overlap their material. Related web-testing slides and notes are available with [Let's Test 2013](../../../letstest/2013/talk/).

The original archive remains unchanged. Tool versions, behaviour, links, and promotional material describe the 2013 workshop.
