## My Quest for Silver Bullets

Keynote presented by Alan Richardson at Software Development Summit, Helsinki, December 2013.

[Conference details on EvilTester.com](https://www.eviltester.com/conference/sdsummit2013_conference/)

This Helsinki version updates the keynote previously presented at TestNet 2013. It explores the search for ideal testing tools, lessons from building and using them, and the importance of keeping responsibility for testing with the people doing the work.
