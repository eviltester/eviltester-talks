## Overview

The tutorial combines demonstrations and practical exercises covering Java, Maven, JUnit, Hamcrest, the WebDriver and WebElement APIs, navigation, interrogation, manipulation, CSS and XPath selectors, synchronisation, and page objects.

The source deck also includes bonus sections on alerts, user interactions, cookies, JavaScript, different browsers, and remote execution, followed by reference pages and summary sheets. These sections are retained in their original order. The exercise deck includes optional exercises and a separate answers section.

## Archive Notes

The sources were recovered from `OneDayHandsOnWebDriver/starEast2014/` inside the archived face-to-face WebDriver training ZIP. Its README identifies this as the version given at STAR East 2014. The tutorial differs from the later generic deck; the selected exercise deck is identical to the generic copy in the same archive.

All 150 tutorial slides and 27 exercise slides were converted to Markdown. Java, XML, and HTML examples remain text, and all 18 source tables were converted to Markdown tables. The tutorial notes retain selector examples, code, and teaching prompts in fenced text blocks.

No PDFs were present in the conference-specific folder. Both PDFs were generated from the selected ODPs using LibreOffice, preserving their original design and all pages. Nineteen annotated slides retain rendered PNGs alongside their Markdown text to preserve callout arrows and grouping. Other illustrations and API mind maps are extracted from the source decks. The 33 included image files are all referenced by Markdown and are shared between the tutorial and exercises where identical.

ODP sources, the ZIP container, generic and STARWEST variants, sales material, course preparation notes, unrelated course exports/code bundles, operating-system metadata, and the local conference planning mind map were omitted. Original archives remain intact.
