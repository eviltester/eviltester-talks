## What do you believe incognito mode should do?

- Write down what you believe incognito mode should do. e.g.
    - unique history,
    - unique cookies,
    - unique bookmarks,
    - each incognito tab is a unique session,
    - etc.

## Find the official documentation

- Find the official documentation for each of the browsers you use.
- You may discover functionality outside the official documentation
- You need to know what to check in the future

## Identify all the ways that you can start incognito mode for each browser

- For each browser that you use,
    - find out all the different ways of entering incognito mode.

## What does Incognito/Private Mode Actually do in each browser?

- Check your beliefs about what incognito mode does e.g. does it actually maintain a unique history? etc.
- Identify what is shared, and what is unique to the session. Your list of beliefs may not have covered all the functionality.

## Reflect on Incognito Mode Features

- Is anything missing from the ‘incognito’ mode?
- If anything is missing, then decide is this a limitation or a benefit?
- How could the variances in incognito mode help your testing?

## Test using incognito/private mode

- Did you test in a different way because you knew that you had access to multiple sessions?
