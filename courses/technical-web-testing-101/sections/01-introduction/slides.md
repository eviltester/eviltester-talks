## Understand the technology under test

- Learn how the application works beneath its interface.
- Investigate architecture, programming, data and communication.
- Use that knowledge to identify risks and choose experiments.
- Let tools extend what we can observe and change.

## Keep learning as the technology changes

- Testing skills transfer between systems; technical details change.
- Ask what happens at each layer of the application.
- Observe, reflect, interrogate and manipulate as the investigation develops.
- Turn an unfamiliar response into the next learning opportunity.
