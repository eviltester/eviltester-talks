### About the conversion

All 267 non-empty PowerPoint text paragraphs are retained. The Markdown includes the map/territory comparison table and readable text from the two embedded diagrams on slides 23-24. Seventeen rendered slide compositions preserve the original artwork, flow diagrams, comparisons, callouts and layout alongside editable text. Only these referenced image files are included.

The nine embedded note paragraphs are separate from the slides. Slides 10 and 11 repeat the same three preparation prompts. The notes on slides 12-13 record historical image URLs. Slide 12 contains only its title in the supplied deck; no replacement image has been added. The notes are not a transcript.

The 31-page PDF was generated from the original PowerPoint with LibreOffice. No retired short links were found in its text or link annotations. The PowerPoint and temporary conversion files are excluded from the release.
