## Web scraping as a Test Design Approach using Selenium 2.0

Also titled *Macho Web Automation in Action*. London Selenium Meetup, August 2011. Alan Richardson.

The talk explains how a registration system's pages, workflows and input limits can supply a model for automation. It covers scraping dropdown values and field lengths, generating random data, using page objects and parameterized tests, and using failures to discover changes and bugs before manual testing.

### About the conversion

The PowerPoint and ODP sources have matching text on all 22 slides: 201 non-empty paragraphs. Neither contains speaker notes. The original 22-page PDF is copied unchanged into `export/`.

The Markdown preserves nested lists and three Java snippets, including their original abbreviated bodies and pseudocode. Non-breaking spaces in the code are normalized to ordinary spaces. These are presentation examples, not a complete runnable project. Rendered slides 15-17 and 21 retain the original code annotations and callout positions alongside their editable text.

Only ten referenced images are included: six native PNGs from the ODP and four rendered slide compositions. The duplicate loose GIF/BMP artwork, original presentation binaries, thumbnail cache and desktop metadata remain in the source archive. Recordings are linked, not included as files.
