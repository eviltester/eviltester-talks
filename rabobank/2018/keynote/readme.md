## Rabobank 2018 Keynote - How to Test with Agility

A keynote about working with agility rather than relying on Agile rituals and definitions, and what testing can look like when adopting that mindset.

## Overview

The keynote discusses agility, exploratory testing, technical testing, automated execution, end-to-end testing, risk, cybernetics, and building a testing approach that fits the project context.
