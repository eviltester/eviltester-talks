# Original Tutorial Abstract

Extracted from the source brief. Biography and submission-form labels are excluded.

Is there more to software testing than test derivation techniques, test strategies and test plan documentation? How important are the skills of a tester?

Skills that allow the tester to question, to learn quickly, to communicate effectively, and to respond based on contextual analysis. These are essential and fundamental skills for both software testing, and the practice of Neuro-Linguistic Programming (NLP).

This tutorial blends NLP models and techniques with Software Testing, offering participants an opportunity to explore different approaches to software testing, and a chance to experiment with practical NLP techniques that can be applied directly to improve their working practices as software testing professionals.

Items to be covered include:

- Harness the NLP Meta Model to identify and deal with ambiguity

- Analysing Context

- Presupposition based software testing

- States of mind for effective testing

Participants will learn a little about NLP in general and more about how to apply NLP specifically to software testing.
