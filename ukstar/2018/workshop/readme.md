## UKSTAR 2018 Workshop - Mapping Cognition to Software Modelling and Testing

A workshop co-presented by Alan Richardson and Gustav Kuhn about magic, cognition, observation, modelling, and software testing.

## Overview

The workshop explores how the study of magic and cognition can help testers think about observation, misdirection, modelling systems, and manipulating systems during technical testing.
