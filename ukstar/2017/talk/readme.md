# Automation and People — What Does Technical Enough Mean?

Alan Richardson's five-slide deck for the conversation session with Isabel Evans at UKSTAR, London, 27–28 February 2017.

- [Slides — Markdown](slides.md)
- [Slides — PDF, five pages](export/slides.pdf)
- [Joint session description](../supporting/session-description.md)

- [Isabel's original description](../supporting/isabel-abstract.md)
- [Conference page on EvilTester.com](https://www.eviltester.com/conference/ukstar2017_conference/)

The deck contains the introduction, conversation prompts and closing contact slide. It has no embedded speaker notes. The generic three-slide conference template is excluded.

The PDF was generated from the original PowerPoint with LibreOffice. In a temporary copy, the headings on slides 3 and 4 were reduced and positioned to avoid clipping at the top of the page. Other content and the original archive remain unchanged. All slide text is readable in Markdown alongside the cover artwork and the three original closing images; unused template graphics are excluded.
