### Dates and sources

The [organiser's archive](https://www.workroom-productions.com/lewt/) confirms the dates and Alan's session titles for LEWT 3 and LEWT 5. It cautions that the diagnosis session's order/content may not be reliable. The local files match those named topics.

The FreeMind file identifies itself as LEWT10 and records preparation on 9 March 2012. That file timestamp does not establish the event date or prove the notes were delivered. The XML-editor folder does not identify an event number or date, so it remains undated.

The Markdown retains the original topic hierarchy, rich-text notes, map connections, anecdotes, examples and spelling. Preparation notes are not transcripts. The archive contains no slide decks or original PDF exports. The diagnosis diagram has a newly generated PDF under its session's `export/` folder. Original editor files remain in the source archive.
