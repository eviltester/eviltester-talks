## Overview

The talk draws on hands-on testing of mobile native and web applications. It examines how device choices, ergonomics, observability, reporting, and technical workarounds affect testing risk.

Examples cover HTTP proxies, Wireshark, laptop hotspots, external keyboards, screen capture, tactical automating, emulators, and simulators. The focus is on understanding technical risks, making deliberate scope decisions, and improving painful parts of the testing process.
