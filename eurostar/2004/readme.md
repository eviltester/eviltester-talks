## EuroSTAR 2004 - Alternative Test Tools in Action

Alan Richardson's presentation and supporting papers for EuroSTAR in November 2004.

- [Presentation: 19 slides and prepared speaker notes](talk/)
- [Four supporting papers](papers/)
- [Sample defect report](examples/)
- [Mind maps, big tools catalogue and blog feeds](supporting/)
- [Conference page and original notes on EvilTester.com](https://www.eviltester.com/conference/eurostar2004_conference/)

The existing conference page states that only the first five or six slides were presented. The complete presentation and session diagrams are retained as supporting material. The source submission records an earlier keynote at the Qbit tools expo in March 2004; these materials supported both uses.

PDFs are under the relevant `export/` folders. Original Word, PowerPoint, MindManager and editor files remain in the source archive. Recorded demonstrations are excluded from this release.
