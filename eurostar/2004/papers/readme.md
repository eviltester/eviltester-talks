## Conversion

The Markdown retains the Word sources' wording, quotations, source credits, lists, tables, exercises and draft placeholders. Floating text-box paragraphs are included once. The papers contain 319, 219, 213 and 42 non-empty text paragraphs respectively. Layout tables become sequential prose or image/caption groups; the actual tool and feed tables remain tables.

All 76 paper illustrations are referenced in the Markdown. Shared raster artwork and identical diagrams are stored once. Native PNG/JPEG images are retained; embedded vector illustrations are rendered to cropped PNGs using LibreOffice. No unreferenced images or editor sources are included.

The three published PDFs are copied unchanged from the archive and match the website's paper downloads. The separate Retrospect draft has no archived PDF, so its PDF was generated from the Word document with LibreOffice. It retains the unfinished statistics placeholders rather than inventing figures.

These are historical drafts. Tool names, costs, operating systems and addresses reflect the original material.

## Image Credits

Illustrations, diagrams, screenshots and tool artwork are retained from the original papers. The source quotations retain their author and publication credits. The archive does not record additional image-credit URLs.
