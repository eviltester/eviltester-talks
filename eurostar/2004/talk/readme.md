## Conversion

The fuller 19-slide PowerPoint supplies 99 substantive editable text paragraphs and 14 prepared-note paragraphs. Empty date/footer placeholders are omitted. The notes are preparation material, not a transcript.

Fifteen rendered slides retain the mind maps, process diagrams, screenshots and annotations. Text embedded in the diagrams is also extracted into Markdown in the PDF's reading order; the images preserve its connections and placement. Descriptive headings have been added to the originally untitled session-diagram slides.

The original 19-page PDF is copied unchanged from the fuller archive version. It includes callouts on slides 2-3 that the existing website PDF omits. The earlier six-slide PowerPoint adds no speaker notes; its small wording differences are retained in the comparison note. Both original PowerPoint files remain in the source archive.

The conference page says only the first five or six slides were presented. The complete deck remains useful as a summary of the papers and as documentation of the test sessions. AVI and Flash demonstrations are excluded from GitHub.
