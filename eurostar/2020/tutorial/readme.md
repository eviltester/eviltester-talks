## EuroSTAR 2020 Tutorial - Technical Web Testing

A hands-on tutorial about using web technology knowledge and tools to expand the scope of testing and identify risks below the GUI.

The tutorial was presented online on 17th November 2020.

## Overview

Understanding the technology of a web application helps us identify risks and find tools to observe, interrogate, and manipulate the system more effectively.

The tutorial covers HTML, the DOM, CSS, JavaScript, HTTP, and APIs, with practical exercises using browser developer tools and applications such as The Pulper, The Todo List App, Test Pages, and API Challenges.

Participants model applications from different perspectives, investigate technology-based risks, experiment with tools, and practise going beyond the visible GUI in their testing.
