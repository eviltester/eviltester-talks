# Tools Guide Source Variants

The release uses `Tools To Help.doc`, retaining its descriptions and VNC links. `Tools To Help2.doc` has three additional descriptions, preserved below. Other differences repeat text from another entry or omit links; the sources have not been silently merged.

## Filemon

Filemon monitors and displays file system activity showing how applications use the files and DLLs. Every event has a timestamp and a report can be output report. Very useful for telling which .dll was in use when a system encounters problems.

## Bochs

This is the free PC emulator. It is a little harder to setup than Virtual PC or VMWare but if you are looking to try this on a low budget then you have nothing to lose.

## Mirek’s MWSnap

Free and requires no install or dll's which makes it perfect for paranoid testers.
