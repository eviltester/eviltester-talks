## EuroSTAR 2012

Materials from Alan Richardson's EuroSTAR 2012 keynote, tutorial, and two webinars.

## Content

- [Unconventional Influences - keynote](keynote/): 19 slides, paper, speaker notes, prepared outline, and script.
- [Selenium Clinic - tutorial with Simon Stewart](tutorial/): the 72-slide public release and speaker notes.
- [Thinking Visually in Software Testing - webinar, 16 May 2012](thinking-visually/): all 45 source slides, speaker notes, and outline.
- [The Evil Tester's Guide to Technical Testing - webinar, 4 December 2012](technical-testing/): 42 slides, prepared script, and outline.

All 178 slides have been converted to Markdown. PDF exports are in each session's `export/` folder. Only images referenced by Markdown are included; editable presentation, document, mind-map, and image editor binaries remain in the original archive.
