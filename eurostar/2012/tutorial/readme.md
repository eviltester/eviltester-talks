## Selenium Clinic

A half-day tutorial presented by Simon Stewart and Alan Richardson at EuroSTAR in November 2012. The session won the conference's Best Tutorial award.

The clinic used participant questions and demonstrations to explore WebDriver, locators, waits, JavaScript, alerts, refactoring, and abstraction. The public slide release also includes reference material from Alan's WebDriver course.

More details:

## Conversion

This is the source version explicitly marked `OnTheDayPublicRelease`. All 72 slides are retained, including the repeated "Implicit or Explicit?" slide present in the original. Java and HTML examples use fenced code blocks; the summary sheet contains 14 Markdown tables. The 38 non-empty speaker-note paragraphs are retained separately as preparation material, not a transcript.

Twenty-eight slides include PNG renders to preserve their callouts, arrows, and diagrams alongside editable text. Other illustrations are extracted from the source. Only referenced images are included.

The PDF retains its original design, with three retired short links and their link annotations removed. Slide 58 has been scaled to fit its page so the clipped beginning of a code line is visible. Other content and artwork are preserved.

The overlapping 66-slide versions, duplicate presentation exports, internal tutorial-planning document, and separate notes about Selenium workshop/build internals are omitted. The published code is linked above; its repository is maintained separately.

The examples and API references retain their historical 2012 wording and code. They have not been updated to current Selenium APIs.
