## The Evil Tester's Guide to HTTP Proxies

Tutorial presented by Alan Richardson at TestNet, May 2013.

[Conference details on EvilTester.com](https://www.eviltester.com/conference/testnet2013may_conference/)

The half-day tutorial introduces technical web-testing models, browser developer tools, HTTP proxies, BurpSuite, and Fiddler. It includes browser and proxy exercises using Google Gruyere, debrief questions, and recommendations for further study.
