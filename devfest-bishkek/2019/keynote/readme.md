## Overview

The talk demonstrates how testing can be split into small chunks with a high-level aim and generic classification. It shows notes from a real testing exercise and explains the planning, recon, modelling, debrief, coverage, exploratory, and admin session types used during the work.

The central message is that lightweight session notes and evidence can make exploratory testing easier to explain, debrief, and generalise into reusable principles.
