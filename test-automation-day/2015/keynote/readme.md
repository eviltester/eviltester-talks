## Overview

The keynote combines practical experience of automating software testing with lessons from the history of automation. It considers the work from the perspectives of testers, automators, and managers.

Topics include choosing clear language and objectives, solving problems through small experiments, changing the testing process, building reusable abstractions, technical recruitment, and learning from older automation and management literature.

## Markdown Conversion

The main deck contains 55 slides and the bonus deck contains 16 slides. Both preserve the original slide order, text, lists, pictures, and hyperlinks. Markdown strikethrough preserves the crossed-out messages on keynote slides 32 and 39; the "Leads To" text on slides 14-16 follows its reading order.

The four text scripts were renamed to `.md`, preserving their content. The introduction's heading was adjusted to render as a Markdown heading. Repeated slide-number and author footers are represented by the slide comments and shared footer directive.
