# SIGIST Winter 2013 — Should Testers Code?

Alan Richardson joined Dorothy Graham, Paul Gerrard and Dr Stuart Reid for a panel at SIGIST Winter 2013 in London on 5 December 2013. The starting question was “Should testers be able to code?”
