# Meta Model — Worked Dialogue

Original prepared questioning example from `metaModelTranscript.txt`; not a transcript of the live tutorial.

\+ The developers on this project are making it hard for the testers to know what has changed.

Generalisation (developers, testers) implied ALL presup - developers are 'deliberately' making it hard deletions (changed with what, 'making it hard' how) comparative deletion (making it hard, compared with what?) lost perform (whole statement) cause effect (no release notes makes it hard to know what has changed)

tackle lost perform "How do you know the developers are making it hard for the testers?"

\+ The developers refuse to write release notes.

mind reading (refuse)

"How do you know the developers 'refuse' to write them. Have you asked them?"

\+ We asked them on a different project and they didn't. They don't write them, and don't want to write them.

we could chase this down as it is a generalisation from specific instances on an old project and the context of this project might be different but we won't.

Test our current model.

"OK, so the developers don't write release notes, and that makes it hard for the testers to know what has changed."

+Yes

tackle the cause effect "So the only way a tester knows what has changed is if they get release notes"

+Well that's the best way

Lost performative statement (value judgement) comparative deletion 'best way' (suggests options)

"Better than what?"

+Better than the tester having to chase the developers, asking questions about the release, and badgering them in to doing their job.

"So the tester could ask questions about the release to find out what has changed."

+Yes, if the developers deigned to speak to the testers, but the developers don't understand that effective communication and documentation is an essential input to the process of software testing.

nominalizations (effective communication, essential input, process, software testing) mind reading (don't understand)

try to bring this back to reality

"How do you know they don't understand that?"

+If they understood they would write the documentation

Complex equivalence
