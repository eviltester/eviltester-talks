## Overview

The talk explores functional testing through systems and models, then extends those models into technical testing. Examples use RestMud and the House of Test data generator to show how observing, interrogating, and manipulating a system at different levels can reveal more risks and defects.

It covers the overlap with security testing, precondition and presupposition analysis, browser developer tools, HTTP proxies, and practical steps for building technical skills.
