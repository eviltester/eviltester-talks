## Push Functional Testing Further Exercises

Exercises to support "Push Your Functional Testing Further" talk presented at March Sigist 2016.

### Systems Theory

* Do some research on Systems Theory - web searches
* Create a reading list from your web search for later study

### Models of Testing

The talk mentions different models of testing: Feedback, Learning, Questioning.

* Create a list of your own 'models of testing'.
    * It might help to think of statements you've used like "Testing is just ..." or "Testing is all about..." because it isn't 'just' or 'all about' but could be modelled 'as if'.
    * If testing is modelled like that... what does it make you think of and how does it apply to testing?

### RestMud

Download a single player version of RestMud from:

* [compendiumdev.co.uk/page/restmud](http://compendiumdev.co.uk/page/restmud)


And approach it as a technical investigation:

* Try playing it
* Use the dev tools and see what else you notice
* Can you use the API?
* Decompile it and see what you learn

### Precondition and Presuppositions

* Pick a web site and examine it for preconditions
* Look at the same web site for presuppositions
* How do your preconditiions and presuppositions differ?

### What functionality does your browser have?

* Work through your chosen browser and look at the features it has e,g.:
    * incognito/private mode
    * dev tools
    * find many many more - try all right clicks and menus
* How can you use that feature in your testing?

### Pick some random web sites

* Read the HTML source
    * Are there any comments?
    * Do you understand the source?
    * Investigate any HTML you do not understand.
