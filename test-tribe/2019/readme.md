# Test Tribe AMA 2019 — Testing and Automation in Testing

Alan Richardson answered questions submitted by The Test Tribe community during a Facebook Live AMA. The Test Tribe subsequently published the recording on YouTube.

- [Full automatic-caption transcript, organised into questions and answers](transcripts/transcript.md)
- [AI-generated question-and-answer summary slides](ama/)
- [Summary slides — PDF](ama/export/slides.pdf)
- [Watch the original recording](https://www.youtube.com/watch?v=I_IK_Q6LwRM)
- [Conference page on EvilTester.com](https://www.eviltester.com/conference/testtribeama_conference/)

The 15 questions cover automation tool choice, IoT testing, lessons from failures, daily automation, video creation, team feedback, the Evil Tester name, scriptless tools, Katalon Studio, environment support, careers, progress, code coverage, recruitment and starting automation.

## Transcript and Summary Provenance

There were no original presentation slides for this AMA. The 16-slide deck in this archive contains a new cover and one AI-generated summary slide per question, created in November 2026 from the recording's automatic captions. Each question slide links to the relevant point in the video and the corresponding transcript section. Recognition errors remain, and the transcript has not been checked word for word against the audio. The summaries have been reviewed against the caption text, not a fresh audio transcription.
