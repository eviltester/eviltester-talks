## Agile Testing Days 2014 - Black Ops Testing Workshop

Workshop by Tony Bruce, Steve Green, and Alan Richardson at Agile Testing Days in November 2014.

More details:

https://www.eviltester.com/conference/agiletestingdays2014_conference/

## Content

- [workshop slides in Markdown](slides.md)
- [original workshop slides as PDF](export/BlackOpsTestingWorkshopATD2014.pdf)

## Overview

Three short introductions lead into hands-on testing of Redmine, with coaching, suggested investigations, interruptions, and group debriefs. The material includes technical exploration, observation tools, note taking, collaboration rules, test-data techniques, and examples of bugs found during preparation.

The original speaker attributions and all 58 slides are retained. Slide 2 includes an announcement for a January 2015 workshop in London, preserved as historical content within this 2014 deck.

## Markdown Conversion

Text, nested lists, hyperlinks, diagrams, and screenshots were converted or extracted from the supplied PowerPoint deck. Only images referenced by the Markdown are included.

The source `blackops` folder contains collaboration plans for this same workshop. Those planning notes were reviewed and omitted from the release, along with the private VM setup material and personal conference notes elsewhere in the source archive.
