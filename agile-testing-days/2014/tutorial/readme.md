## Overview

The tutorial combines agile working, exploratory testing, systems thinking, and technical investigation through practical exercises using Redmine.

It covers working beyond user stories, modelling the application and development process, using browser developer tools and HTTP proxies, learning technical skills, taking testing notes, and communicating the value and risks of technical testing.
