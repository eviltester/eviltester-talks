## Overview

The keynote explores how to judge automated execution by how it copes when things are not working well. It covers differences, failure handling, process models, automation paths, system models, synchronisation, assertions, and why BDD tooling is not the same thing as BDD.

The central message is that many of the secrets of automated execution are things we already know: prioritisation, abstraction, modelling, flexibility, preconditions, postconditions, and making automated execution trustworthy by testing it against failure.
