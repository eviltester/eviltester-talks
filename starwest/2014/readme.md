## STARWEST 2014 - WebDriver Tutorial and Automation Abstractions

Materials from Alan Richardson's two sessions at STARWEST in October 2014.

More details:

https://www.eviltester.com/conference/starwest2014_conference/

## Content

- [Tutorial: Hands On WebDriver - One Day](tutorial/)
- [Talk: Automation Abstractions: Page Objects and Beyond](talk/)

The tutorial contains the STARWEST-specific four-slide introduction and 180-slide main deck. The track session contains 52 slides. All three decks have been converted to Markdown, with PDF exports generated from their original ODP sources using LibreOffice. Speaker notes are retained separately. Images are included only where referenced by the Markdown.
