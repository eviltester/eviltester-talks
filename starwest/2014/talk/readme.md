## Automation Abstractions: Page Objects and Beyond

Alan Richardson's track session at STARWEST in October 2014.

More details:

https://www.eviltester.com/conference/starwest2014_conference/

An overview of ways to model automation abstraction layers: page objects, DOM elements, navigation, application actions, domain objects, and higher-level interfaces. Java examples illustrate the design choices and their effects on readability and maintenance.
