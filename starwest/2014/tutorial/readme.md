## Hands On WebDriver - One Day

Alan Richardson's STARWEST 2014 tutorial. The conference-specific introduction is dated 13 October 2014.

More details:

https://www.eviltester.com/conference/starwest2014_conference/

The tutorial covers the WebDriver API, browser navigation and interrogation, element manipulation, CSS and XPath selectors, synchronisation, custom expected conditions, and page objects. This STARWEST revision uses more code templates for the exercises than the earlier STAR East version.
