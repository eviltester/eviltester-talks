## Lessons Learned with BDD

Thinking and Automating with Domain Specific Languages.

Alan Richardson's half-day tutorial at the Test Management Summit in January 2013. This opinionated overview treats BDD as modelling communication through a shared domain language. It combines discussion and paper exercises with demonstrations of Cucumber-JVM, FitNesse, and a custom DSL using the Tracks application.

More details:

https://www.eviltester.com/conference/tmsJan2013_conference/
