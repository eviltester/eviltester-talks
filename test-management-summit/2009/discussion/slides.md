# Have you noticed any Trends about Commercial vs O/S?

Commercial tools

- Hide the scripting (-)
- Proprietery &amp; Unattractive scripting languages (-)
- Tools for testers (-)
- Do All Things (-)

Open Source

- More technically demanding (+)
- Common Programming Languages (+)
- Use by Dev &amp; Test (+)
- Specialised (+)
