## Automation Abstractions

Alan Richardson's facilitated session at the Test Management Summit in London, April 2014.

More details:

https://www.eviltester.com/conference/testmanagementsummit2014_conference/

The session explores brittle automation, abstraction design, page objects, element and domain abstractions, Gherkin, and domain-specific languages. Java examples compare a test with and without abstraction before opening the discussion to participants' experiences, problems, decisions, biases, successes, and possibilities.
