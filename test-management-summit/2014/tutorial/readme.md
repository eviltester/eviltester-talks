## Introduction to Selenium WebDriver - The Talky Bits

Alan Richardson's half-day tutorial for managers at the Test Management Summit in London, April 2014. The main deck uses the title "Hands On WebDriver: The Talky Bits - Half Day Training".

More details:

https://www.eviltester.com/conference/testmanagementsummit2014_conference/

This session introduces Selenium WebDriver through presentations, demonstrations, and questions. It covers Java and Maven setup, WebDriver and WebElement APIs, navigation and interrogation, manipulation, synchronisation, custom expected conditions, and page objects.

## Markdown Conversion

All source slides are retained in order. Java, XML, and HTML examples use fenced code blocks; the two summary sheets are represented by 16 Markdown tables. The 25 substantive speaker-note paragraphs are retained separately.

Eleven annotated slides also include PNG renders to preserve their arrows, brackets, and callouts alongside editable text. Native pictures and diagrams were extracted from the original files, sharing duplicate assets between the introduction and main deck. Only referenced images are included.

Both PDFs were generated from `TutorialIntroSlide.odp` and `handsOnWebDriverTalkyBits.odp` using LibreOffice, preserving the original slide design.
