## Fusion Birmingham 2017 Talk - A Technical Deep Dive into Practical Test Automation

A technical deep dive into practical test automation, using examples from Agile projects to discuss API and GUI automation, abstractions, system modelling, stress testing, exploratory testing support, CI assertions, and tactical versus strategic automation.

## Overview

The talk explains how automation can support testing beyond simple regression checks, with an emphasis on useful abstractions, development practices, and automation approaches that help testers and teams work more effectively.
