## Overview

The tutorial explores page objects, domain objects, element and component abstractions, navigation, synchronisation, fluent interfaces, and Gherkin. Participants model and automate TodoMVC, then compare the choices made in their abstraction layers.

## Archive Notes

All 73 slides were converted from the original `abstractionLayersLetsTest2014.odp` inside the source archive ZIP. This preserves the 2014 conference version, including its historical links, repeated slides, final local-app installation slide, Java examples, and Gherkin example. Code examples are fenced blocks in Markdown; they have not been updated to a newer Selenium API.

The PDF was generated with LibreOffice because the archive contained no slide PDF. Temporary export copies received small layout corrections on slides 8, 11, and 14 to keep edge text visible and separate the code blocks. The original source files were not changed. The one-page diagram handout was copied unchanged.

Speaker notes are retained for slides 43, 48, 49, 50, 51, and 73. Only images referenced by Markdown are included. The ZIP's additional Markdown conversion was omitted as a second slide source, along with the tutorial planning mind map, ODP, ZIP container, and operating-system/editor metadata.
