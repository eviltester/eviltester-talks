## Overview

This workshop uses browser games and technical testing challenges to practise browser developer tools, JavaScript console use, DOM inspection and manipulation, REST API interaction from the browser, REST clients, custom headers, and HTTP requests.

Participants play games, find bugs, fix bugs, write code, improve bots, and develop technical testing skills through hands-on exercises.
