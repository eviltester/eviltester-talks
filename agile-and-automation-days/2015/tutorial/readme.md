## Overview

The tutorial brings together agile working, exploratory testing, systems thinking, and technical investigation through exercises using Redmine.

It covers testing beyond user stories, browser developer tools, HTTP proxies, APIs, modelling the application and development process, taking testing notes, and explaining the risks and value of technical testing.

## Markdown Conversion and Original Exports

The Markdown contains all 102 slides from the ODP source, with editable text, nested lists, and extracted images. The original PDF has 101 pages: it omits source slide 62, "Tools". The Markdown retains that slide.

The eight-page keynote print handout contains the complete 48-slide deck, with six slides per page. It is retained alongside the tutorial materials for printing. The full-size keynote PDF is in the [keynote folder](../keynote/).

The three testing-session handouts were renamed from `.txt` to `.md`, retaining their original content. They record example testing sessions against a local Redmine instance.
