## Overview

Improving technical test ability involves developing models, identifying gaps in knowledge, and practising how to observe, interrogate, and manipulate an application at different levels.

The talk uses web browsers, developer tools, HTTP proxies, and mobile testing examples to show how those skills develop. It discusses requisite variety, limiting beliefs, reflection, and the work involved in learning new technology.
