## Agile Tour London 2017 - Effective Software Testing for Modern Software Development

A talk about adapting testing for modern software development approaches such as Agile, DevOps, CI, continuous delivery, automated execution, and risk-based decision making.

## Overview

The talk explains how testing changes when it is built into the wider system of development, and how testers can use risk, observation, feedback, tooling, and abstraction to support customised development processes.
