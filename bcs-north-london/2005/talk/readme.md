## Context Driven Testing, A Personal View

Alan Richardson's short presentation to North London BCS on 16 March 2005. The cover uses the title "It Depends... Context Driven Testing - What does it mean to have no best practices?"

The talk explores context-driven testing, the assumptions behind best practices, questions that reveal the context, and what others can expect from context-driven testers.
