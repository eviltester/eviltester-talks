# Resolutions and Trends in Software Testing

Xebia meetup, Hilversum — Alan Richardson, January 2017.

- [Published preparation notes](preparation-notes.md)
- [Recording on YouTube — talk and Q&A](https://www.youtube.com/watch?v=3qIyLwY9Z3s)
- [Conference page on EvilTester.com](https://www.eviltester.com/conference/xebiameetup2017_conference/)
- [Year overview](../)

The conference page describes a 20-minute talk including Q&A, filmed on a mobile phone. The published notes were the prompts Alan glanced at while speaking. They cover testing trends, machine learning, IoT, tactical and strategic automating, personal responsibility and renewing resolutions.

The notes retain the original wording, emphasis and list hierarchy. They are preparation material rather than a transcript. Source: the [existing website document](https://github.com/eviltester/eviltester-com-source/blob/07db3b3b7eadb58eb21b21e619fd9131a20339fd/hugo/content/conference/xebiameetup2017_conference.md).
