# Xebia Meetup 2017 — Resolutions and Trends in Software Testing

Alan Richardson gave a short talk, including Q&A, at Xebia in Hilversum in January 2017, the evening before TestBash Netherlands. The talk covered resolutions, responsibility for testing and building on existing skills when exploring trends.
