## EPIC Experience 2020 - Prepared Materials for a Cancelled Conference

TechWell's EPIC Experience conference was scheduled for 19th - 23rd April 2020 in San Diego. The cancellation notification was dated 13th March 2020, and the conference was cancelled because of the COVID-19 pandemic.

These talk and tutorial materials were prepared for the cancelled conference. The sessions were not delivered at that event.

More details:

https://www.eviltester.com/conference/epicconference2020_conference/

The cancellation is also recorded in [Inflectra's event notice](https://www.inflectra.com/Company/Event/epic-sponsorship-by-inflectra-in-2020-953.aspx).

## Content

- [Prepared talk: A Guide to Testing Web Applications](talk/)
- [Prepared tutorial: Agile Technical Exploratory Testing Workshop](tutorial/)

## PDF Exports

Both sessions include PDFs in their `export` subfolders. They use the shared [Marp theme](marp-theme.css) with black backgrounds, red headings, and yellow body text. Each session README includes the command to regenerate its PDF from the original Markdown.
