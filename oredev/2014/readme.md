## OREDEV 2014 - Security Testing and Automation Abstractions

Two track sessions presented by Alan Richardson at OREDEV in Sweden in November 2014.

More details:

https://www.eviltester.com/conference/oredev2014_conference/

## Content

- [Confessions of an Accidental Security Tester](accidental-security/)
- [Automation Abstractions: Page Objects and Beyond](automation-abstractions/)

Both slide decks have been converted to Markdown. The original conference PDFs are retained unchanged under each session's `export/` folder. The automation talk also includes notes from the presentation source.

Only images referenced by Markdown are included. Annotated slides and the HTTP diagram retain renders from the original PDFs alongside their Markdown text, preserving arrows, callouts, and image positioning.
