## Overview

The talk examines the choices behind automation abstraction layers: page objects, domain objects, element and component abstractions, navigation, synchronisation, fluent interfaces, and Gherkin. Examples compare different ways to automate TodoMVC and identify the modelling decisions behind them.

The example code and later workshop material are in the [Selenium WebDriver Compendium](https://github.com/eviltester/seleniumWebDriverCompendium/tree/main/automationAbstractions). The 2014 slides retain their original xp-dev links as part of the conference material.
