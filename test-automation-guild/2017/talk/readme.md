## Test Automation Guild 2017 Talk - If you want to automate, you learn to code

A talk about why automating effectively requires learning to code and learning to code well, with a focus on tactical versus strategic automation.

## Overview

The talk explains that automating does not simply mean automating testing. It covers automating parts of the test process, using tools tactically, learning to code for strategic automation, refactoring, abstractions, libraries versus frameworks, and how to build more flexible long-term automation.
